# Exact structural integer proofs (opt-in)

`--integer-structure` currently enables parity proofs for linear MILP input with all columns integer. Unsupported structures fall through unchanged. It cannot be combined with `--presolve` until original-index certificate postsolve exists. Default behavior is unchanged.

The module accepts exact integral parsed-double coefficients/RHS of magnitude <= 2^40, at most 2048 columns/equalities and 4096 rows. It performs GF(2) elimination with original-row provenance. Contradictions are independently recomputed from original rows before returning infeasible. General integer residues are never treated as fixed values. A unique point is reported only when all binary columns (exact [0,1]) are fixed and each remaining integer column occurs in a single exact equality whose other columns are fixed binaries; auxiliaries, bounds and all original rows are checked with bounded int64 arithmetic. Input tokens are interpreted under the existing parsed-double model semantics, not arbitrary-precision decimal semantics.

`structural_certificate` in MILP JSON contains zero-based original row combinations. Unique proofs also export the original-space point. `benchmarks/structural_integer_replay.py` independently loads the original input, verifies combinations in Fraction arithmetic, uniqueness, feasibility and objective. It rejects corrupted proofs. `structural_integer_tests.py BINARY FIXTURE_DIRECTORY` covers official enlight files and adversarial unsupported cases.

This is an integer infeasibility proof, not an LP Farkas certificate. No claim is made that the continuous relaxation is infeasible. Preserve integer-proof labeling.

## Objective lattice lane

The same flag detects a narrow objective-only epigraph: minimize negative cost*t with nonnegative continuous t; every incident row is exactly t-y<=0, and each continuous y appears only in this link and one equality q*y plus integral coefficients on integer columns = integral RHS. Common positive exact integer q is required; y has [0,+inf], t upper bound, if finite, lies on 1/q grid. At optimum t is min(y,upper), so the objective lies on an offset grid. The solver rounds valid inherited/node LP lower bounds upward with an outward margin. It does not round arbitrary continuously costed objectives. For maximization the existing minimization-normalized model is used. Certificate exports the links/equalities; independent replay validates exact structure and original-space solutions. Generic B&B supplies the lower-bound proof; structural replay is not an independent full-tree proof.
